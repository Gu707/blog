PROJETO · XADREZ

Ferramentas para Xadrez

Uma coleção de ideias e ferramentas digitais para tornar o treinamento de xadrez mais prático.

Objetivo

Criar experiências simples que ajudem estudantes a desenvolver atenção, reconhecimento de peças atacadas e tomada de decisão durante o jogo.

Tecnologias

HTML, CSS e JavaScript, mantendo a proposta de aplicações leves que podem ser hospedadas como páginas estáticas.

Status

Em desenvolvimento. Esta página funciona como o espaço de documentação do projeto e poderá receber demonstrações e links conforme as ferramentas forem publicadas.
